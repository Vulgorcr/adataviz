# Adataviz - Eau de Paris
[voir le site en ligne] (https://adataviz-vulgorcr.netlify.app)
## Présentation
Application web permettant de découvrir
les commerces partenaires de l'Eau de Paris.

## Source des données
Open Data Paris :
commerces-eau-de-paris

## Fonctionnalités
- Affichage des commerces
- Recherche par adresse
- Filtre par rue
- Tri alphabétique
- Statistiques

## Installation
npm install

## Lancement
Utiliser Live Server dans VS Code.

## Tests
npm test
